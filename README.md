## 🚀 Sobre o projeto

Pequeno sistema desenvolvido na disciplina de frontend como trabalho. O website foi criado para uma empresa aeroespacial brasileira fictícia, com objetivo de informar o público sobre seus programas espaciais.

### 🎯 Objetivo

Informar a população sobre programas espaciais desenvolvidos ou planejados pela empresa.

### 👥 Público-alvo

Brasileiros interessados em astronomia.

---

## 🛠 Tecnologias utilizadas

* **HTML**
* **CSS**
* **JavaScript**

> **Banco de Dados:** Nenhum
> **APIs externas:** Nenhuma
> **Infra/Deploy:** Nenhum

## ⚙️ Instalação e execução local

### 🔑 Pré-requisitos

* Navegador moderno com suporte a HTML, CSS e JavaScript

### 📦 Passos

```bash
# Clone o repositório
git clone https://github.com/BarrosoTiago/WebsiteBraverso.git

# Acesse a pasta do projeto
cd WebsiteBraverso
```

### ▶️ Como rodar

Abra o arquivo `index.html` no navegador.
